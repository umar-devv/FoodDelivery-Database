# 📂 Data Files

This folder contains the raw JSON data for the **Food Delivery Database**.

## Files Included:
- `customers.json` - Customer records
- `restaurants.json` - Restaurant information
- `menuitems.json` - Menu items with prices
- `orders.json` - Order history
- `riders.json` - Delivery rider details
- `payments.json` - Payment transactions

## How to use:
1. Open **MongoDB Compass**.
2. Create a database named `FoodDeliveryDB`.
3. Click on each collection and use **`Import File`** to upload these JSON files.
