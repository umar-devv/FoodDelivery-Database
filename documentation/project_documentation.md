# Food Delivery Database - Project Documentation

## Project Overview
This project is a NoSQL database built using MongoDB to manage a food delivery system.

## Technologies Used
- MongoDB (NoSQL Database)
- MongoDB Compass (GUI Management)
- Java 17 (Programming Language)
- Maven (Build Tool)

## Database Collections
1. Customers - User profiles and order history
2. Restaurants - Partner restaurant details
3. MenuItems - Food items and pricing
4. Orders - Customer order tracking
5. Riders - Delivery personnel details
6. Payments - Transaction records

## Key Features Implemented
- CRUD Operations (Create, Read, Update, Delete)
- Aggregation Pipeline for reporting
- Indexing for performance optimization
- Java-MongoDB integration

## GitHub Repository Structure
- `/data` - JSON sample data files
- `/queries` - MongoDB query examples
- `/reports` - Generated reports from Java
- `/documentation` - Project documentation
