==================== AGGREGATION QUERIES ====================

1. Calculate Total Revenue from Delivered Orders:
   db.Orders.aggregate([
       { $match: { "status": "Delivered" } },
       { $group: { _id: null, total_revenue: { $sum: "$grand_total" } } }
   ])

2. Count Orders per Restaurant:
   db.Orders.aggregate([
       { $group: { _id: "$restaurant_name", order_count: { $sum: 1 } } },
       { $sort: { order_count: -1 } }
   ])

3. Most Popular Food Items:
   db.Orders.aggregate([
       { $unwind: "$items" },
       { $group: { _id: "$items", order_count: { $sum: 1 } } },
       { $sort: { order_count: -1 } }
   ])

4. Payment Method Statistics:
   db.Payments.aggregate([
       { $group: { _id: "$method", total_amount: { $sum: "$amount" } } },
       { $sort: { total_amount: -1 } }
   ])
